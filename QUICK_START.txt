STATEMENT IMPORTER - WINDOWS QUICK START

RECOMMENDED: Install Neon Ledger from Microsoft Store after the listing is published.
DEVELOPER/LEGACY INSTALLER: StatementImporter-1.6.0-Setup-x64.exe

1. Use 64-bit Windows 10 build 17763+ or Windows 11.
2. Install from Microsoft Store. The Store package includes PostgreSQL tools, needs no administrator access, and receives signed Store updates.
3. Click Set up storage and continue. Watch the current step and elapsed time; the importer opens when ready. Advanced users may connect an existing PostgreSQL server instead.
4. Select one or more bank statement files and click Reconcile and import.
5. Refresh your database or DBeaver connection to see newly inserted rows.
6. Open Backups & Access to create a verified backup and an optional read-only reporting login.
7. Open Updates to confirm Store-managed updates. Legacy installations retain manual GitHub checks.
8. If database setup fails, open Diagnostics to run local checks and create a privacy-safe report ZIP. Review it, then use Prepare email to support.

Supported statement structures:
- State Bank of India (SBI)
- ICICI Bank
- IndusInd Bank

The app creates the required tables automatically. Statement passwords are never saved.
The PostgreSQL password is protected for the current Windows account using Windows DPAPI.
Pending unmapped statements are also DPAPI-protected and deleted after 24 hours.

Microsoft signs an accepted Store MSIX. Development MSIX files are not publicly trusted and are not for general distribution.
Check the GitHub release page for the actual signing status of any legacy installer.
Only distribute software and financial tools in accordance with applicable privacy and banking rules.
